# [기획] 실시간 주문 현황 v2 (가상)

## 진입
- 주문내역 탭에서 진행 중인 주문을 누르면 실시간 주문 현황 화면으로 이동한다.

## 주문 상태
- 주문 상태는 접수 대기, 조리 중, 배달 중, 배달 완료의 4단계로 표시한다.
- 현재 단계는 강조 표시하고, 지나간 단계는 완료 표시한다.

## 예상 도착 시간
- 가게가 주문을 접수하면 예상 도착 시간을 "HH:mm 도착 예정" 형식으로 표시한다.
- 가게가 접수하기 전에는 예상 도착 시간 대신 "도착 시간 계산 중"을 표시한다.

## 주문 취소
- 주문 취소 버튼은 주문 후 5분 이내이면서 접수 대기 상태일 때만 노출한다.

## 결제 정보
- 결제 금액은 주문 금액에 배달팁을 더하고 할인 금액을 뺀 값으로 표시한다.
- 쿠폰이 적용된 주문은 결제 정보에 적용된 쿠폰명과 할인 금액을 표시한다.
- 쿠폰을 여러 장 적용한 주문은 적용된 쿠폰명을 모두 표시한다.
